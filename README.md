# Fake Social Media Account Detection

A machine learning prototype that predicts whether an account is **Real** or **Likely Fake** from structured profile features.
Stack: Python, Pandas, NumPy, Matplotlib, Scikit-learn (Logistic Regression, Decision Tree, Random Forest), Flask API, React frontend.

```
User -> React interface -> Flask API (app.py) -> saved ML model -> prediction -> interface
```

## Important: the dataset is synthetic
`data/accounts.csv` is generated by `generate_dataset.py` so the project runs end to end.
The scores in `reports/` are therefore **not real-world results**. For your final submission, download a real labeled
fake-account dataset (for example from Kaggle), rename/map its columns to the ones below, save it as `data/accounts.csv`,
and re-run the notebook.

Required columns: `account_id, followers, following, posts, account_age_days, has_profile_pic, has_external_url, is_verified, is_fake`
(`is_fake`: 1 = fake, 0 = real; the flag columns are 0/1).

## Setup (VS Code terminal, from this folder)
```
python -m venv venv
venv\Scripts\activate          # Windows   (macOS/Linux: source venv/bin/activate)
pip install -r requirements.txt
```

## Run order
1. `python generate_dataset.py`  (skip if you use a real dataset)
2. Open `fake_account_detection.ipynb` in VS Code and **Run All** (or run `python train.py`, which runs the same steps).
   This cleans the data, draws the EDA charts, trains the 3 models, compares them, and saves `models/best_model.joblib`.
3. `python app.py`, then open http://localhost:5000

## What is where
| Item | Location |
|---|---|
| Raw and cleaned dataset | `data/accounts.csv`, `data/accounts_clean.csv` |
| EDA notebook | `fake_account_detection.ipynb` |
| EDA charts, confusion matrices, comparison table | `reports/` |
| Saved final model and its metrics | `models/best_model.joblib`, `models/metrics.json` |
| Shared feature code (training and API) | `features.py` |
| API | `app.py` (`POST /predict`, `GET /model-info`, `GET /health`) |
| Prediction interface | `frontend/` |

## API example
```
POST /predict
{"followers":120,"following":1800,"posts":3,"account_age_days":20,"has_profile_pic":1,"has_external_url":1,"is_verified":0}
-> {"prediction":"Likely Fake Account","probability_fake":0.9853,"is_fake":true,"model":"Logistic Regression"}
```

This is a prediction tool, not proof that an account is fraudulent.
